## Problem statement
Examine regional crop production, rainfall, fertilizer usage and soil types to identify factors **associated with** higher agricultural yields. All findings are associations in synthetic data and do **not** prove causation.

## What the project does
| # | Task | # | Task |
|---|------|---|------|
| 1 | Load and inspect data | 9 | Irrigated vs rain-fed yields |
| 2 | Missing values and duplicate `Farm_Record_ID` | 10 | Rainfall / fertilizer / yield correlations |
| 3 | Handle missing `Rainfall_mm` and `Soil_pH` | 11 | Crop × Season productivity |
| 4 | Yield per hectare (division-by-zero safe) | 12 | NumPy median, variance, quartiles |
| 5 | Total production, average yield | 13 | IQR outliers (overall and within crop) |
| 6 | Rank crops by yield | 14 | Rainfall categories (Low/Moderate/High) |
| 7 | Compare regions/districts | 15 | Five cautious recommendations |
| 8 | Compare soil types | | |

### Cleaning approach (summary)
* Text labels trimmed and standardised; duplicate `Farm_Record_ID` rows removed (first record kept).
* Missing `Rainfall_mm` → median of the same region; missing `Soil_pH` → median of the same soil type (overall median as fallback); imputed rows are flagged.
* Rows with missing or zero `Area_Hectares` are excluded from yield calculations only.
* Extras beyond the brief: crop-adjusted yield index, Spearman correlations, within-crop IQR outliers, charts.

## How to run
```bash
git clone <your-repository-url>
cd <repository-folder>
python -m venv .venv
# Windows: .venv\Scripts\activate      macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook src/analysis.ipynb      # then: Kernel > Restart & Run All
# or:  cd src && python analysis.py
```
The dataset `data/16_crop_yield.csv` is already included. To recreate it, run `python data/generate_dataset.py`.

* `irrigation_impact_summary.csv` – irrigated vs rain-fed summary

## Limitations
Synthetic data (generated by script, not real farm records); observational associations only; group-median imputation is an assumption; crop type confounds most comparisons; weather timing, temperature, variety and management are not in the data.
